 # Student Task Planner
 
 A professional and responsive task management web application built using HTML, CSS, and javaScript.

## Features

- Add new task
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by status and priority
- Track task progress
- Save tasks using Local Storage
- Dark Mode and Light Mode
- Responsive design for mobile desktop

## Technology Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure

Student-Task-Planner/
index.html
style.css
script.js
README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
